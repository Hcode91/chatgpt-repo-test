# LocalPaint Android inpainting (experimental)
Source archive at `localpaint/source.tar.xz`. GitHub Actions extracts it and builds an ARM64 Android debug APK using stable-diffusion.cpp.

This is a proof-of-concept, not verified on physical hardware. The model is not included. The app is designed for importing a compatible SD1.5 inpainting safetensors file.

Build workflow: [LocalPaint Android APK](../../actions/workflows/localpaint-android.yml).

The source package is also supplied separately as a ZIP in the ChatGPT conversation. Existing repository branches are not modified.
