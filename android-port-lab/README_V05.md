# v0.5: Upstream boot test on Android ARM64

The application adds a substantially different test from previous versions:
it executes the **actual, fully linked upstream `ps3recomp_boot_smoke`**
binary built with Android NDK ARM64, together with the upstream synthetic
`smoke.elf` generated by `tools/make_smoke_elf.py`.

It captures startup/exit diagnostics (64 KB cap), has a watchdog that kills
the subprocess after 25 seconds, and does not accept arbitrary user-selected
ELFs for execution. The older clean-room v0.4 PPU tests remain available.

Build: CI compiles the full upstream ps3recomp static archive with SDL2 +
libucontext for Android, links its real boot loader/HLE/LV2 test harness, then
packages the resulting ARM64 PIE executable as a private native package
payload. The Android application launches this file from its nativeLibraryDir.

Caveats:
- A successful CI build validates cross-compilation and packaging, not
  Android execution or PS3 emulation correctness. The boot process may fail,
  be denied execution by Android's sandbox, hang, or be killed for memory.
- The synthetic test does not have commercial game code or assets.
- An Android Vulkan RSX graphics renderer is not yet implemented, and the
  Linux headless RSX backend isn't a game renderer.
- The app is a porting test lab, NOT a playable inFAMOUS APK.

First hardware test: press "BOOT REAL PS3RECOMP RUNTIME (EXPERIMENTAL)".
The log should show real init progress and either a clean finish or the
specific runtime fault we need to diagnose.
