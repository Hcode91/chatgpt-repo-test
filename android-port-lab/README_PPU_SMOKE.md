# PPU guest execution milestone

This proof-of-concept moves beyond Vulkan/memory probes: it generates an
original, clean-room PPC64 ELF64 program with a real PS3-style OPD, lifts the
original PowerPC instruction bytes using upstream `ps3recomp/tools/ppu_lifter.py`,
compiles that generated code for **Android ARM64**, and executes the lifted
function through its generated function table. It verifies the expected GPR
result (71 from r3=5) and fails if unexpected HLE or guest-memory calls occur.

Current scope is intentionally narrow: the test does not yet use
`ppu_load_elf`, execute the OPD through the full boot scaffold, start PS3
threads, or render RSX graphics. This is NOT a playable inFAMOUS build.

## Reproducibility
All clean-room inputs are generated by `tools/generate_ppu_smoke.py`.
GitHub Actions invokes the original toolkit's PPU lifter with a single named
function. It builds and runs a native Linux x86-64 validation binary first,
then compiles the same output into an Android JNI library. No user game assets
are needed.

Output APK is in the workflow artifact named `infamous-android-arm64-probe`.
In the app choose "Run recompiled PPU instructions" to test actual ARM64 execution.

## Next engineering milestone
Replace the one-function isolated bridge with the toolkit's real
`ppu_load_elf` loader and its PPU dispatch/boot path, then boot the complete
upstream smoke ELF. That requires runtime/HLE integration and platform
compatibility fixes; do not mistake this smoke test for that result.
