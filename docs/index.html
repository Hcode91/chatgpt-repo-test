Why doesn't this app run ColdFlesh yet?

A standard SD 1.5 checkpoint needs a separate text encoder, VAE and UNet inference pipeline, a diffusion scheduler (LCM in this case), and a browser-compatible conversion. The 1 GB file size alone doesn't mean 1 GB of memory use. Activations, weights, GPU staging and browser overhead can exceed it. MI-GAN is a small single-pass inpainting model used only as a WebGPU proof of concept.
